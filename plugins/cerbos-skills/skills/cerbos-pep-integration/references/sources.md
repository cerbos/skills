# Sources

The guidance in this skill is checked against the Cerbos release named by `targetsCerbosVersion` in `SKILL.md`, and the per-language references against the SDK releases current at that time. When moving to a new release, run `evals/update_cerbos_version.py`, read that release's notes and the release notes of each SDK below, then recheck each page against the section or reference file it backs — in particular the request and response fields, batch limits, `auxData` keyset rules, the TLS defaults of each client, and which query-plan adapters are documented.

## SDKs and protocols

- [cerbos-sdk-javascript](https://github.com/cerbos/cerbos-sdk-javascript), [cerbos-sdk-go](https://github.com/cerbos/cerbos-sdk-go) (API on [pkg.go.dev](https://pkg.go.dev/github.com/cerbos/cerbos-sdk-go/cerbos)), [cerbos-sdk-python](https://github.com/cerbos/cerbos-sdk-python), [cerbos-sdk-java](https://github.com/cerbos/cerbos-sdk-java), [cerbos-sdk-net](https://github.com/cerbos/cerbos-sdk-net), [cerbos-sdk-rust](https://github.com/cerbos/cerbos-sdk-rust), [cerbos-sdk-php](https://github.com/cerbos/cerbos-sdk-php), [cerbos-sdk-laravel](https://github.com/cerbos/cerbos-sdk-laravel) and [cerbos-sdk-ruby](https://github.com/cerbos/cerbos-sdk-ruby): install, connecting, TLS defaults, the four calls, query plans, JWT auxiliary data and errors in the matching `references/<language>.md`; the language table in `SKILL.md`.
- [cerbos/query-plan-adapters](https://github.com/cerbos/query-plan-adapters), including [Ent](https://github.com/cerbos/query-plan-adapters/tree/main/ent) and [pgx](https://github.com/cerbos/query-plan-adapters/tree/main/pgx): the undocumented reference adapters in `query-plan.md`, `go.md`, `java.md` and `ruby.md`. These have no tagged releases; recheck their state each time.
- [`cerbos/cerbos/api/public`](https://github.com/cerbos/cerbos/tree/main/api/public) and the OpenAPI document a running PDP serves at `/schema/swagger.json`: the wire shapes in `api-shapes.md`.
- [OpenID AuthZEN](https://openid.github.io/authzen/): the AuthZEN façade in `api-shapes.md` and AuthZEN in `go.md`.
