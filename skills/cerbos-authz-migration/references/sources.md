# Sources

This skill pins no release: it links the `latest` Cerbos PDP and Synapse docs and the current Cerbos Hub docs, and the guidance is checked against those. When a Cerbos release changes policy evaluation, the policy model, `PlanResources` or Hub's store, deployment or audit features, read the release notes, recheck each page below against the file it backs, then run `scripts/fix-links` over the skill.
