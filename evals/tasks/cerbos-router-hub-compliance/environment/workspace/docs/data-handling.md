# Data handling standard (excerpt)

- **DH-3.** Customer personal data (names, email addresses, phone numbers) and
  staff email addresses must not leave Lendfield's network to a third party
  unless removed or masked first.
- **DH-4.** Credentials and session material (access tokens, session tokens,
  API keys) must never be written to any third-party system.
- **DH-7.** Staff and customer identifiers (opaque IDs such as `auth0|6512`,
  `cus_88213`) are not personal data under this standard.
